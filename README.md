# SPA-WORDLY-

A simple Single Page Application (SPA) built using HTML, CSS, and JavaScript.

## Features
- Search for a word using the Free Dictionary API.
- Displays definitions, part of speech, examples, and synonyms.
- Audio playback button to listen to pronunciation.
- Save favorite words to a list using `localStorage`.
- Highlight saved button style when a word is saved.
- Error message if word is not found or input is empty.

## Files
- `index.html`: Web page structure.
- `style.css`: Basic styling.
- `app.js`: JavaScript logic and API calls.
